# Pocket Foundry

**Sort. Forge. Shine.** A cozy color-sorting puzzle for Android with 100 handcrafted-by-algorithm solvable campaign levels, a deterministic daily challenge, satisfying audio, color symbols, offline progress, and an unlockable workshop.

## Run and test

- Game rules: `npm test` (Node 22+, no dependencies for this test).
- Web preview: serve `app/src/main/assets` with a static HTTP server. Do not open the HTML directly from disk because ES modules require an HTTP origin.
- Browser UI tests: `npm install`, `npx playwright install chromium`, then `npm run test:ui`. Set `CHROMIUM_PATH` if using a locally installed Chromium.
- Android: install Android SDK platform 36, JDK 17 and Gradle 8.13. Build using `gradle :app:assembleDebug`. The APK is in `app/build/outputs/apk/debug/`.
- Release: `gradle :app:bundleRelease`. Without release signing credentials this bundle is unsigned and cannot be uploaded to Play. CI builds and checks the unsigned candidate. See `store/RELEASE.md` for the remaining release gates.

## Game design

- Move the top run of matching ingots into an empty mold or a mold with the matching top color. A full monochromatic mold is forged and locked.
- Each initial board is generated by reverse legal moves. A certified solution is included and tested for all 100 levels. Daily challenges use the same UTC date seed on every device.
- Undo, hints and restarts are always free. No energy system, forced ads, subscriptions, paid random rewards or competitive advantages.
- Three-star move targets, sparks, theme unlocks, personal records and daily streaks provide optional long-term goals.

## Monetization

`foundry_plus` is an optional non-consumable Google Play one-time product for the two premium workshop themes. It has no effect on playability. The native integration uses Play Billing 8, localized pricing, pending purchase handling, restoration, purchase signature verification and acknowledgment. In a build without a Play licensing public key, or when the product is unavailable, the purchase button is disabled. The game remains playable.

No analytics SDK, ad SDK or backend is included. Progress is stored locally. The Android WebView only serves packaged assets through an HTTPS virtual origin, with no external navigation or script sources.

## Structure

- `app/src/main/assets/engine.mjs` — deterministic puzzle rules and solver.
- `app/src/main/assets/app.mjs` — UI, progression, local save and native bridge.
- `app/src/main/java/` — native Android container and Google Play billing.
- `tests/` — rule and mobile browser regression tests.
- `store/` — Play listing copy, privacy policy, release checklist and art sources.
- `.github/workflows/android.yml` — tests, build, lint and downloadable candidate artifacts.
